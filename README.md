# 今天吃什麼？

一個幫「不知道今天要吃什麼」的人做決定的靜態網頁。讀者啟動入口的科技魔法陣進入網站，回答 5 個問題（或玩小遊戲讓緣分決定），系統依回答推薦一道餐點，並可進一步搜尋附近符合的店家。

## 檔案結構

純前端靜態網站，無需後端、無需資料庫，4 個檔案：

- `index.html` — 頁面結構（入場動畫、問答區、小遊戲彈窗、結局動畫、結果卡片）
- `style.css` — 所有樣式與動畫
- `script.js` — 互動邏輯
- `data.js` — 餐點資料庫、問題定義、結局定義

## 功能一：入場動畫（科技魔法陣）

- 真實星空照片背景（NASA 星雲照片，公共領域）
- 讀者點擊魔法陣 → 三層同心圓環（六邊形 HUD 外框、六芒星中層、內層星點）持續旋轉，並帶有旋轉掃描光束（雷達感）
- 點擊後掃描加速、光暈變亮，顯示「讓我帶你找到今天想吃的美食吧！」與「帶我進入美食世界 →」按鈕
- 點擊按鈕淡出入場畫面，進入主要問答頁

## 功能二：5 題問答

每題以卡片呈現，含進度條、原創吉祥物插畫、題目、選項 chip：

1. **今天心情如何？** 開心 😊／普通 😐／有點累 😪／心情不好想療癒一下 🥺／想放縱一下 🎉／不確定，抽張塔羅牌 🔮
2. **想吃辣的嗎？** 完全不辣 🙅／小辣即可 🌶️／越辣越好 🔥／不確定，擲個骰子 🎲
3. **想吃哪種料理？** 中式／西式／日式／韓式／東南亞／不限／不確定，抽支籤 🎋
4. **預算大概多少？** $ 平價／$$ 中等／$$$ 奢侈／不限／不確定，轉個輪盤 🎡
5. **想吃正餐還是想吃點心？** 正餐 🍚／湯品 🍲／點心甜點 🍰／飲料 🧋／都可以／不確定，轉個輪盤 🎡

可用「← 上一題」返回修改。

## 功能三：不確定時的小遊戲

每題都有「不確定」選項，點下去會彈出全螢幕深紫色遮罩，播放對應小遊戲動畫（約 2 秒），隨機決定該題答案後自動跳下一題：

- **塔羅牌**（心情題）：卡片翻轉動畫，正面顯示抽到的心情
- **骰子**（辣度題）：骰子快速旋轉後停下，顯示隨機骰面 + 結果
- **抽籤**（料理類型題）：籤筒中一支籤彈出，顯示抽到的料理
- **輪盤**（預算 / 餐點類型題）：轉盤快速旋轉後停止，顯示停在的選項

## 功能四：10 種「終焉」結局動畫

答完 5 題後，先依所有回答做加權計分（心情命中 +3、辣度命中 +2、料理類型命中 +2、預算命中 +1、餐點類型命中 +2），從最高分的餐點中隨機挑一道 → 依該餐點對應的「終焉」類型，播放全螢幕結局動畫（漸層背景、飄浮粒子效果、詩意標題與副標題），約 2-3 秒後顯示「看看是什麼 →」按鈕，點擊才揭曉最終餐點。

10 種原創終焉（**注意**：全部用色調、光影、詩句原創呈現，不重現任何動畫或影視作品的畫面，避免版權問題）：

| 結局 | 標題 | 詩句 | 色調 |
|---|---|---|---|
| calm | 靜謐終焉 | 喧囂落幕，留下的只有恰到好處的安寧。 | 深藍→水藍 |
| warm | 溫柔終焉 | 像回家的那盞燈，永遠留一盞給你。 | 深褐→暖橘 |
| nostalgic | 懷舊終焉 | 時間繞了一圈，你還是想念最初的味道。 | 深棕→米黃(復古) |
| fiery | 熱血終焉 | 戰鬥結束的那一刻，痛快勝過一切。 | 深紅→橘紅 |
| grand | 華麗終焉 | 這一餐，值得盛大登場。 | 深紫→金黃 |
| adventure | 冒險終焉 | 地圖的邊界，是下一口的起點。 | 深青→亮青 |
| romantic | 浪漫終焉 | 有些美味，值得細細品味到最後一口。 | 深紫紅→粉紅 |

每道餐點都在 `data.js` 中標記對應的 `ending` 類型。

## 功能五：附近店家搜尋（免費方案，無需 API 金鑰）

結果卡片有「📍 幫我找附近店家」按鈕：

- 用瀏覽器 `navigator.geolocation` 取得使用者座標
- 呼叫 OpenStreetMap 的 Overpass API（`https://overpass-api.de/api/interpreter`，完全免費、不需金鑰）查詢方圓 5 公里內 `amenity=restaurant`，並依料理類型關鍵字過濾
- 用 Haversine 公式計算距離，依「距離」由近到遠排序，列出前 8 筆
- 頁面上會註明：「資料來源：OpenStreetMap，依距離排序（免費地圖無公開評價分數，若需要以評價排序需串接 Google Places API 金鑰）」

> ⚠️ 若之後想升級成「依 Google 評價排序」，需要自行申請 Google Maps Platform 的 Places API 金鑰（需綁信用卡），再把 `script.js` 裡 `queryNearbyRestaurants()` 換成呼叫 Google Places Nearby Search API。

## 其他功能

- **精靈再想想**：在結果卡片重新從最高分餐點中隨機抽一次（不重播結局動畫）
- **重新回答**：清空所有答案，回到第 1 題

## 視覺設計

- 入場畫面：真實星空照片背景 + 原創 SVG 科技魔法陣（電光藍／青色調、六邊形 HUD 框架、六芒星、旋轉掃描光束）

- 純 CSS/JS 動畫，零外部函式庫依賴
